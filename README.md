# Number Guessing Game

A simple C++ console game where the player tries to guess a randomly generated number between 1 and 10.

## What I Practised

- Functions
- Variables
- User input and output
- `while` loops
- `if/else` statements
- Random number generation
- Tracking program state

## How It Works

The program generates a random number between 1 and 10.

The player enters guesses until they find the correct number. After each incorrect guess, the program tells the player whether their guess was too high or too low.

The program also keeps track of the number of guesses taken.
